# Estelle's Kitchen — React + Vite starter

## Run locally
1. Install Node.js LTS.
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm run dev` and open the local URL Vite displays.

## Included
- Responsive React homepage and navigation
- Six service cards for the agreed service list
- Forest-green, ivory and muted-gold visual system
- Enquiry form with required-field validation and copyable WhatsApp message
- Mobile navigation and responsive layouts

## Before launch
- Replace illustrative photography with approved brand images.
- Add Estelle's confirmed WhatsApp number before enabling direct WhatsApp handoff.
- Add a privacy notice and decide whether enquiries should be stored in Supabase.
- Finalise and export production logo assets and favicon.
- Test accessibility, image loading, performance and the live enquiry flow.

The current form does not store customer data. It prepares a message for the user to copy.
